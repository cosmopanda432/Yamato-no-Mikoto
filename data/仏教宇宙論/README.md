## 取得方法(再現用)

CBETA 公式 GitHub `cbeta-org/BM_u8`(UTF8 平文版大正蔵)から巻単位で raw ダウンロードし、品/巻の
境界(`grep -n` で `品第N` `卷第N` マーカーを特定)で切り出した。

```bash
curl -s "https://raw.githubusercontent.com/cbeta-org/BM_u8/master/T/T01/new.txt" -o T01_new.txt  # 長阿含經(起世經と同volume)
curl -s "https://raw.githubusercontent.com/cbeta-org/BM_u8/master/T/T04/new.txt" -o T04_new.txt  # 仏伝文献(佛所行讚・佛本行經)
curl -s "https://raw.githubusercontent.com/cbeta-org/BM_u8/master/T/T29/new.txt" -o T29_new.txt  # 倶舎論
```

CBETA の行形式は `T01n0024_p0310a06P##本文` (経典ID_頁行タグ##本文)。タグ文字(`_`=継続 /
`P`=段落開始 / `D`=品題 / `J`/`j`=巻題 / `N`/`A`=注記・訳者)に応じて連結し、`[…]` 脚注番号・
`<mj NNN>` 外字画像参照を除去、`<p>` のみ段落区切りとして保持した(抽出スクリプトは本セッションの
scratchpad、再利用時は再実装または要相談)。

## 用語差異(anchor 設計時の注意)

同じ須弥山でも経典により訳語が違う。**anchor は経典ごとに正しい訳語を使うこと**(逐語接地なので
訳語を跨いだ hit は起きない)。

- 起世經 / 世記經(旧訳系): **須彌山**
- 倶舎論(玄奘新訳): **妙高山**(意訳) / **蘇迷盧**(音写)
