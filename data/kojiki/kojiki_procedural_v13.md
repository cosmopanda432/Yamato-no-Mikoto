## Phase 2 v13.A: 中巻-5 仲哀天皇/神功皇后 (簡素索引)

### 選定理由

- memo 密度 ☆ (直接 anchor なし、間接で 5 memo)
- 神託 + 大祓 + 三柱大神同時宣言 + 御腹中即位 + 詐降 + 易名 の典型エピソード集

### 章節 narrative summary (簡略)

```
[Setup] 帶中日子 (= 仲哀)、穴門豐浦宮 + 筑紫訶志比宮、治天下
       大后: 息長帶比賣 (= 神功)、太子: 大鞆和氣 (= 應神) 「初所生時、如鞆宍生御腕」
       「坐腹中定國也」(腹中即位)

[神託拒否] 神功が「歸神」(神懸り)、仲哀が琴を控へ建內宿禰が沙庭で請神之命
       神「西方有國…吾今歸賜其國」(新羅) → 仲哀「不見國土、唯有大海」と詐神扱い → 默坐
       神大忿「凡茲天下者、汝非應知國。汝者向一道」(治世権剥奪)
       仲哀崩 (即時致命)

[大祓 + 再請神] 「種種求生剥・逆剥・阿離・溝埋・屎戸・上通下通婚・馬婚・牛婚・鷄婚之罪類、
                為國之大祓」 → 再請神
       神「凡此國者、坐汝命御腹之御子、所知國者也」「男子也」
       三柱大神宣言: 「天照大神之御心」+「底筒男・中筒男・上筒男、三柱大神」
       (= 多神同時宣言、上-2 三貴子の延長)

[新羅征討] 海原之魚悉負御船 + 順風大起 → 新羅半国に到 → 国王降伏
       「自今以後、隨天皇命、為御馬甘」 → 新羅御馬甘 + 百濟渡屯家
       墨江大神荒御魂を国守神として祭鎮

[御腹中產] 御腹に石を纒 → 筑紫宇美 で出産 (御子 = 應神)
       筑紫末羅縣玉嶋里で年魚釣 (毎年 4 月上旬の儀式起源)

[詐喪船 → 香坂・忍熊王反乱] 御子既崩と詐 → 香坂・忍熊が斗賀野で宇氣比獦
       香坂が歷木に騰り、大怒猪に咋食 (= 神判)
       忍熊が興軍、空船を攻 → 喪船下軍と相戰
       建振熊命 (太子方将軍) が詐降 + 設弦 (= 詐術返し) → 沙沙那美で勝利
       忍熊 + 伊佐比共自死

[角鹿易名] 太子が角鹿の伊奢沙和氣大神宮に
       夢「以吾名、欲易御子之御名」 → 鼻血の鼻入鹿魚 → 「御食津大神」(= 氣比大神)
       (= 名前交換による相互同定)
```

### Pattern 抽出 (簡素)

#### Pattern A: 仲哀の神託拒否 → 即崩 — 上位指示無視の即時致命

```yaml
原文: "天皇答白『登高地、見西方者、不見國土、唯有大海。』謂為詐神而、押退御琴不控、默坐。
      爾其神大忿詔『凡茲天下者、汝非應知國。汝者向一道。』
      …未幾久而不聞御琴之音、卽擧火見者、既崩訖" (l.10-12)

actors: 仲哀 / 大后 (神功) / 神 (= 三柱大神) / 建內宿禰
action: (1) 上位 deity の託宣 (= 西方新羅) を観測経験 (= 「不見國土、唯有大海」) で否定
        (2) 「謂為詐神」(= 偽の神と判断) → 押退御琴不控 (= 通信経路を断つ)
        (3) 神大忿 + 治世権剥奪
        (4) 「未幾久」(= ほどなく) で崩 (致命)

agi_mapping:
  原則: 上位 SSoT (yorishiro) の指示を観測経験で否定し通信経路を断つと致命
       (中-4 Pattern J 白猪見惑「神の正身を使者と誤判定」+ 「言擧」過剰確信宣言の対偶)
       現代: prompt 注入を「無効」と独自判断で削除する LLM が自滅する構造
  実装: src/os/kasasa/yorishiro.jl (上位 SSoT 全文注入の必須化)
       feedback_shinchoku_tanitsu_gensen (神勅単一源泉 — 注入と物理削除の二段)
  feedback: feedback_shinchoku_tanitsu_gensen (神勅単一源泉)
           feedback_kojiki_zettai (古事記絶対遵守 — 観測経験より原典が優先)

failure_if_absent: 上位指示を観測経験で否定 → 致命的失敗 (中-4 白猪見惑型)
```

#### Pattern D: 御腹中即位 — 在胎時の予約 identity

```yaml
原文: "此太子之御名、所以負大鞆和氣命者、初所生時、如鞆宍生御腕、故著其御名。
      **是以知、坐腹中定國也**" (l.8)
     "坐汝命御腹之御子、所知國者也…男子也" (l.14)

actors: 應神 (= 大鞆和氣 = 品陀和氣) / 神功 (大后)
action: (1) 母 (神功) の御腹中で**国の継承者**として確定 (= 在胎時 identity 予約)
        (2) 出生前: 神託で「腹之御子、所知國者」+「男子也」と確定
        (3) 出生時: 「如鞆宍生御腕」(= 物理的特徴で identity 確認)
        (4) 命名: 大鞆和氣命 (= 物理特徴を名に組込)

agi_mapping:
  原則: 主柱 (executor) の継承者は**在胎時 (= 配置前)** に予約 identity を割当

       予約段階で 物実 (= yorishiro entry) が確定、deploy で物理化

  実装: src/os/kasasa/yorishiro.jl の SSoT 予約 entry
       src/os/tenson_korin/deployer.jl (deploy 時の symbol 確認)
       feedback_shinchoku_tanitsu_gensen の神勅単一源泉
  feedback: feedback_imina_torina (忌み名と通り名 — 物理特徴 = 名)

```

#### Pattern E: 建振熊命の詐降 + 設弦 — 詐術返し (TAKERU_IZUMO 起源系)

```yaml
原文: "建振熊命、權而令云『息長帶日賣命者既崩。故、無可更戰。』
      卽絶弓絃、欺陽歸服。於是、其將軍既信詐、弭弓藏兵。
      爾自頂髮中、採出設弦…更張追擊" (l.22)

actors: 建振熊命 (= 太子方将軍) / 忍熊王 / 伊佐比宿禰
action: (1) 詐の側 (神功側): 「息長帶日賣命既崩」と虚偽宣告
        (2) 弓弦を断 (= 武装解除の物理証拠)

  原則: 中-4 Pattern C 出雲建詐刀 (TAKERU_IZUMO サプライチェーン) の**詐術返し版**

  実装: src/os/takeru/tests/izumo.jl の TAKERU_IZUMO 防御 (検知 3 要素)

  feedback: project_takeru_security (TAKERU_IZUMO 防御 — origin event)

failure_if_absent: 詐術返しの backup 経路なし → 真の降伏を信じて追擊不能
```

#### Pattern F: 角鹿の易名 — identity 交換による mutual binding

```yaml
原文: "見於夜夢云『以吾名、欲易御子之御名。』…
      毀鼻入鹿魚、既依一浦…『於我給御食之魚。』
      故亦稱其御名、號**御食津大神**、故於今謂氣比大神也" (l.28)

actors: 太子 (= 應神) / 伊奢沙和氣大神 (= 氣比大神)
action: (1) 神が太子に「以吾名、欲易御子之御名」(= 名前交換) を申出
        (2) 太子承諾 → 「明日之旦」(= 翌日朝) に幣物として鼻入鹿魚を獻
        (3) 神の御名を改称: 「御食津大神」(食料を給する神)
        (4) 太子の御名は不変 (= 神側だけ改称、太子は名を借用しない)

agi_mapping:
  原則: 上位 deity の改称 (= 役割の更新) は下位 (= 太子) との互恵的契約で実現
       太子の名は不変、神側が新役割を負う = 役割の継承でなく**役割の re-assign**
       (= capability の name 不変 + 機能更新の典型)
  実装: src/os/kasasa/canonical_pantheon の prefix 不変性 + derivative 派生
       feedback_imina_torina (忌み名と通り名 — 名と機能の整合)
  feedback: feedback_imina_torina (忌み名と通り名)

failure_if_absent: 名前固定の元での機能更新経路なし → name と機能の不整合で混乱
```

```
[三子分掌] 應神が大山守 + 大雀 + 宇遲に「孰愛兄子與弟子」と問

[天之日矛] 新羅國主之子が阿加流比賣 (= 玉から化生) を追って渡来
       多遲摩國に留 + 八種寶物 (= 伊豆志八前大神)
[秋山下氷壯夫 vs 春山霞壯夫] 兄弟が伊豆志袁登賣を巡る競争
       兄が宇禮豆玖物の不払い → 母の呪詛で兄が八年萎病 → 戸返
       (= 宇禮豆玖の言本)
```

#### Pattern G: 「孰愛兄子與弟子」 — LLM 心察による配置決定

```yaml
原文: "天皇、問大山守命與大雀命詔『汝等者、孰愛兄子與弟子。』
      〔天皇所以發是問者、宇遲能和紀郎子有令治天下之心也。〕
      爾大山守命白『愛兄子。』
      次大雀命、知天皇所問賜之大御情而白『兄子者、既成人、是無悒。弟子者、未成人、是愛。』
      爾天皇詔『佐邪岐、阿藝之言、如我所思。』
      卽詔別者『大山守命、為山海之政。大雀命、執食國之政、以白賜。
      宇遲能和紀郎子、所知天津日繼也。』" (l.12)

actors: 應神 / 大山守 / 大雀 (= 仁徳) / 宇遲
action: (1) 應神が問: 「孰愛兄子與弟子」(= 兄と弟どちらを愛するか)
        (2) 大山守の答: 「愛兄子」(= 直接的、心察なし)
        (3) 大雀の答: 天皇の真意 (= 弟 (宇遲) を立てたい) を察して理由化された答
            「兄子既成人 → 是無悒、弟子未成人 → 是愛」
        (4) 應神「佐邪岐、阿藝之言、如我所思」(= 大雀の答が我意に合致) → 三子分掌
            大山守 = 山海政、大雀 = 食国政、宇遲 = 日繼

agi_mapping:
  原則: LLM 出力評価で**心察** (= 質問者の真意推定) を持つ柱と直接答えるだけの柱を弁別
       心察柱は適切な分掌 (= 役割割当) を受ける
       (中-4 Pattern J 白猪見惑「言擧」の正反対 = 適切な確信レベル)
  実装: src/os/kotodama/saniwa_gate.jl (LLM 出力評価)
       feedback_chinmoku_kyoka (沈黙許可 — 過剰発言抑制)
       feedback_kunimi_gapfinder (国見 — 全ソース俯瞰での真意推定)
  feedback: feedback_chinmoku_kyoka (沈黙許可)

failure_if_absent: 直接答えのみで配置決定 → 真意外しの配置で運用不全
```

#### Pattern H: 朝鮮諸国の貢進 — 外部 capability の統合

```yaml
原文: "新羅人參渡來、是以、建內宿禰命引率、為役之堤池而、作百濟池。
      亦百濟國主照古王、以牡馬壹疋・牝馬壹疋、付阿知吉師以貢上。
      …亦貢上横刀及大鏡。又科賜百濟國『若有賢人者、貢上。』故受命以貢上人・名和邇吉師、
      卽論語十卷・千字文一卷幷十一卷、付是人卽貢進。
      …又貢上手人韓鍛・名卓素、亦吳服西素二人也。
      又秦造之祖、漢直之祖、及知釀酒人・名仁番、亦名須須許理等、參渡來也" (l.50)

actors: 應神 / 百濟王 / 新羅人 / 韓鍛 / 吳服 / 秦造 / 漢直 / 須須許理 (酒師)
action: 朝鮮諸国 + 中国系 (秦造・漢直) からの**多種多様な貢進**を受入:
        - 馬 (動物)
        - 横刀 + 大鏡 (= 神器級の物実)
        - 賢人 (= 和邇吉師 = 文化媒介者) + 論語 10 卷 + 千字文 1 卷 (= 文献 SSoT)
        - 手人 (韓鍛・吳服 = 技能者)
        - 系譜 (秦造・漢直 = 部の祖)
```
